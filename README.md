# MED-R5 UI (wired to engines)

This bundle contains:
- `frontend/` (Vite + React UI)
- `backend/` (FastAPI API that calls your existing engine folders)

## 1) run backend

```bash
cd backend
python -m venv .venv
# windows:
.venv\Scripts\activate
# mac/linux:
# source .venv/bin/activate
pip install -r requirements.txt

# copy your engine zip files into backend/ then:
python setup_engines.py

uvicorn app:app --reload --port 8787
```

Health check:
- `http://localhost:8787/api/health`

## 2) run frontend

```bash
cd frontend
npm i
npm run dev
```

The UI calls the backend at `http://localhost:8787`.

## Notes
- Drug lists and case flows are intended for research-mode workflow review, not direct real-world execution.
- Hypothesis + 5 early-kill experiments are generated by backend endpoint `/api/hypothesis/bundle`.
- Safeguard analysis is generated by backend endpoint `/api/safeguard/analyze`.
- Best local posture is backend on + frontend on, so registry-backed rows and export governance stay aligned.
